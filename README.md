# 🌺 LI ONO NIHA - Web Chatbot Bahasa Nias

Aplikasi Web Chatbot dan Penerjemah Bahasa Nias berbasis AI untuk mendukung preservasi bahasa daerah di kalangan mahasiswa, pemuda, dan masyarakat pendatang di Nias.

---

## 👥 Kelompok 3
- **Proyek:** Chatbot Edukasi & Preservasi 'LI ONO NIHA'
- **Target Pengguna:** Mahasiswa, Anak Muda, Pendatang di Nias

---

## 🚀 Cara Menjalankan di VS Code

1. Install Ekstensi **Live Server** di Visual Studio Code.
2. Buka file `index.html`.
3. Klik kanan pada area editor lalu pilih **Open with Live Server**.
4. Dapatkan API Key Gemini gratis di [Google AI Studio](https://aistudio.google.com/).
5. Masukkan API Key pada menu **Pengaturan API Key** di aplikasi web.
